# Lab 4: Informed Search - Heuristics & A*

## Overview
This repository contains the solution for Artificial Intelligence Lab 4. It implements A* search, Uniform Cost Search (UCS), and an overestimate heuristic experiment.

## Files in this Repository
- **lab4_astar.py**: Python script containing the graph implementation, A* algorithm, UCS check, and overestimate test.
- **Lab4_Report.docx**: Complete lab report including manual calculations, comparison tables, and reflections.

## How to Run the Code
Make sure Python is installed on your system. Run the following command in your terminal or command prompt:

```bash
python lab4_astar.py
